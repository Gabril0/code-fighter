# FizzBuzz

Print the numbers from `1` to `N`, one per line, but with two twists:

- For multiples of **3**, print `Fizz` instead of the number.
- For multiples of **5**, print `Buzz` instead of the number.
- For multiples of **both 3 and 5** (i.e. multiples of 15), print
  `FizzBuzz`.

## Input

A single line with one integer `N` (`1 <= N <= 100000`).

## Output

`N` lines. Line `i` (for `i` from `1` to `N`) contains `Fizz`, `Buzz`,
`FizzBuzz`, or the number `i` itself, according to the rules above.

## Example

Input:
```
5
```

Output:
```
1
2
Fizz
4
Buzz
```
